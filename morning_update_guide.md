# Morning hit/miss update guide

Use `hardrock_beats_tracker.csv` every morning:

1. Update **Actual Plays** for each beat from your platform analytics.
2. Set **Hit or Miss**:
   - `HIT` if `Actual Plays >= Target Plays`
   - `MISS` if `Actual Plays < Target Plays`
3. Change **Morning Confirmed** from `NO` to `YES` when the row is reviewed.
4. Add notes for context (for example: "boosted by reel", "needs repost").

Tip: Duplicate the latest day rows to keep this tracking going daily.
